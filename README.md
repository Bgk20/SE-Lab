
# Software Engineering Lab

A collection of seven Software Engineering laboratory submissions covering requirements engineering, project documentation, Python implementation, code quality analysis, test coverage, and fuzz testing.

```
requirements & UML
        |
        v
Jira & software engineering documentation
        |
        v
Python implementation
        |
        v
Static code analysis & quality validation
        |
        v
Code coverage & fuzz testing
```

## Repository layout

| **Folder / file** | **Content** |
| -------------------------------- | ------------------------------------------------------------------------------ |
| `Lab 1/` | **Pharmacy Expiry & Re-order Dispatch Engine** — functional requirements, non-functional requirements, UML use-case diagram, and FEFO dispensing-list use-case specification. |
| `Lab 2/` | **Jira Documentation** — Jira-related lab submission and documentation. |
| `Lab 3/` | **Software Engineering Lab 3** — lab submission document. |
| `Lab 4/` | **Catch-the-Fish Game** — Python game implementation, game modules, test file, supporting videos, and LLM chat evidence. |
| `Lab 5/` | **Code Quality Analysis** — Energy System application, original implementation, Bandit security analysis, Flake8 and Pylint reports, issue documentation, and reflection. |
| `Lab 6/` | **Code and Branch Coverage Analysis** — Coffee Shop Order application, separate code-coverage and branch-coverage test suites, and coverage screenshots. |
| `Lab 7/` | **Fuzz Testing and Input Validation** — Python input-processing application, Hypothesis-based fuzz tests, fixed implementation, PDF report, and screenshots. |
| `.gitignore` | Excludes Python cache files, pytest cache, coverage data, and compiled Python files. |

## Lab highlights

**Lab 1 – Requirements Engineering**
- Functional and non-functional requirements.
- UML use-case diagram.
- FEFO (First Expiry, First Out) dispensing workflow.
- Use-case flow specification.

**Lab 2 – Jira**
- Jira-related lab documentation and submission.

**Lab 3 – Software Engineering**
- Software Engineering laboratory documentation.

**Lab 4 – Python Game Development**
- Catch-the-Fish game implementation.
- Modular Python code.
- Supporting test file and evidence.

**Lab 5 – Code Quality and Security**
- Energy System application.
- Static code analysis using Bandit, Flake8, and Pylint.
- Issue identification and reflection.

**Lab 6 – Code Coverage**
- 20 code-coverage tests achieving 100% line coverage.
- 15 branch-coverage tests achieving 100% branch coverage.
- Separate test suites and coverage reports.

**Lab 7 – Fuzz Testing**
- Property-based testing using Hypothesis.
- Input validation and error handling.
- Three fuzz tests passed after fixing the application.
- Before-and-after testing evidence.

## Getting the repository

Clone the repository:

```bash
git clone https://github.com/Bgk20/SE-Lab.git
cd SE-Lab
```

## Repository navigation

- Each lab has its own dedicated folder.
- Open `.docx` and `.pdf` files for documentation and reports.
- Review Python source files and their corresponding tests for implementation-based labs.
- Check the `Evidence/` and `Screenshots/` folders for supporting evidence.
- Refer to individual lab README files for additional details and instructions.
