Software Engineering Lab
A central repository for the Software Engineering laboratory work. It brings the lab submissions together in one place, with documents, source code, tests, reports, and supporting evidence organised by lab number.
Repository Contents
Lab	Overview	Main contents
[Lab 1](./Lab%201/)	Pharmacy Expiry & Re-order Dispatch Engine	Functional and non-functional requirements, UML use-case diagram, and the use-case flow specification for generating a FEFO dispensing list.
[Lab 2](./Lab%202/)	Jira lab documentation	Lab 2 Jira documentation/report.
[Lab 3](./Lab%203/)	Software Engineering Lab 3	Lab 3 documentation/report.
[Lab 4](./Lab%204/)	Catch-the-fish game	Python game implementation, supporting game modules, test file, and supporting evidence including video and LLM-chat material.
[Lab 5](./Lab%205/)	Code quality and security analysis	Energy-system application files, input data, and analysis outputs/reports from Bandit, Flake8, and Pylint, together with issue and reflection notes.
[Lab 6](./Lab%206/)	Code and branch coverage analysis	Coffee-shop order application and tests demonstrating line coverage and branch coverage.
[Lab 7](./Lab%207/)	Fuzz testing and input validation	Python input-processing application, Hypothesis-based tests, fuzzing report, screenshots, and supporting notes.

Each lab is kept in its own folder. Open the relevant folder to view its submission files and supporting material. Where a lab contains a report, README, screenshots, tests, or other evidence, those files are kept with that lab.
Getting the Repository
Clone the repository:
git clone https://github.com/Bgk20/SE-Lab.git
cd SE-Lab
Browsing the Labs
- Start with the lab folder you need from the table above.
- For document-based submissions, open the included .docx file.
- For programming labs, review the source files and the tests or reports included in that lab folder.
- Check the lab-specific README or report for any experiment details and instructions.
This repository is maintained as a collection of Software Engineering laboratory submissions and supporting evidence.
